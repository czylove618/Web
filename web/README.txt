# 属性计算器（Web 版）

一个纯前端的角色属性计算器，用于计算游戏队伍中五名角色经过皮肤/点化转换后的进场属性、附加属性，以及首回合回血参考值（部分角色）。

无需安装、无需后端，双击 `index.html` 即可使用。

#数据输入

⠿ 拖拽手柄	按住可上下拖动行，交换角色顺序（顺序影响转换池累加）
角色顺序		下拉选择该行的角色
体/攻/灵/防	角色的基础属性，单位：万
皮肤1/2/3	输入或选择皮肤名，支持模糊匹配

#皮肤输入支持

输入即筛选：键入关键字后自动过滤下拉列表（子串匹配，不区分大小写）
右键查看详情：在皮肤输入框上右键，显示该皮肤的转换规则（源属性 → 目标属性，百分比）

#按钮功能

📁 选择工作目录	授权一个文件夹，之后配置的保存/导入都在此目录进行
导入配置		从工作目录或本地文件加载配置
导出配置		将当前输入保存为 JSON 文件（工作目录或下载）
保存为默认	将当前输入设为此后启动时的默认配置（config.json）
加载默认		手动重新加载之前保存的默认配置（config.json）
重置为初始	回到内置的初始配置（app.js中写死的配置）

#配置优先级
config.json（工作目录）  →  localStorage（浏览器缓存）  →  BUILTIN_DEFAULT（app.js中兜底配置）
config.json 被手动编辑后格式错误会自动回退到 localStorage 或内置配置

#项目结构
web/
├── index.html      # 页面骨架、按钮、模态框、脚本引入顺序
├── style.css       # 全部样式（布局、表格、自动补全下拉、模态框、tooltip）
├── init.js         # 静态数据（若后续新增皮肤、皮肤转换比例/类型错误，均在此文件更改）
│                    ├─ conversionMap    皮肤 → 转换规则
│                    ├─ roleMap          角色 ID → 角色名
│                    ├─ skinIncludeMap   皮肤全称 → 规则简化名
│                    ├─ qianYuan         乾元皮肤 → 双规则名
│                    └─ roleBaseRule     角色 → 基础转换规则
├── calc.js         # 计算逻辑
│                    ├─ calculate()          主入口
│                    ├─ calRole()            角色基础转换
│                    ├─ calindition()        皮肤转换
│                    └─ printFinalResult()   结果输出
├── fs.js           # 文件系统封装
│                    └─ Workspace  工作目录授权、读写文件
└── app.js          # UI 逻辑
                     ├─ BUILTIN_DEFAULT        内置默认配置
                     ├─ AutoCompleteComboBox   自动补全组件
                     ├─ Row                    单行组件
                     ├─ DefaultConfig          默认配置管理（三层优先级）
                     ├─ 拖拽排序
                     └─ 导入/导出/保存/加载逻辑
